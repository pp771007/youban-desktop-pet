# 用 ChatGPT 出圖的提示詞

規範本體：桌寵 → `pet-pack-spec.md`；UI → `design-system.md`。這份是照規範寫好、可以直接貼的提示詞。
第一隻桌寵：**Q 版水豚**。

## 流程

| 步 | 出什麼 | 用途 |
|---|---|---|
| 0 | 風格探索：同一隻水豚 4 種畫風 | 你挑一種，之後全家族（桌寵＋UI）都照它 |
| 1 | 角色設定稿 | 之後每一張都附上它，維持長相一致 |
| 2 | 動作圖 | 桌寵本身 |
| 3 | UI 風格稿 | 我照著用程式實作，不直接放進程式 |
| 4 | App 圖示 | 主視覺，我轉成多尺寸 |
| 5 | 空狀態插圖 | 清單沒東西時的畫面 |

- **桌寵開一個對話、UI 開另一個對話**，每個對話只做一件事，AI 比較記得住
- 從第 1 步起，每次都**附上前面定稿的圖**當參考
- 歪掉的單張重出，不用全部重來

## 透明背景先驗證

所有圖都要真正的透明背景。**第 0 步的風格探索圖出來後先傳給我**，我驗它是不是真的有透明通道：

- 是 → 照這份繼續
- 不是（畫出灰白棋盤格、或白底）→ 我改提示詞或換做法，不要硬做下去

自己大概看一下的方法：下載的 PNG 放到深色背景上看（例如 Telegram 深色模式傳給自己），
四周還看得到灰白格子 = 那是畫出來的假透明。

## 第 0 步：風格探索

```
我要做一個 Windows 桌面寵物 app，主角是一隻 Q 版水豚。先做風格探索。

角色：圓滾滾的 Q 版水豚，暖棕色短毛，小圓耳朵，豆豆眼，一臉悠哉，頭上頂著一顆小橘子。2～3 頭身，正面偏 3/4 站姿。

請把同一隻角色用 4 種不同的畫風各畫一次，排成 2×2 四格，每格標一個代號（A、B、C、D）：
A. 柔和厚塗插畫風：細膩的明暗與毛流，溫暖光線
B. 精緻平塗貼圖風：乾淨俐落的輪廓線，賽璐璐兩階陰影
C. 3D 軟膠公仔質感：像高品質收藏公仔的渲染，柔和的次表面散射
D. 細緻像素風：高解析度像素藝術，邊緣乾淨

品質要求：商業產品等級，細節乾淨、比例精準、光源統一從左上方來。
縮小到 128 像素時仍要一眼認得出輪廓與表情。
背景：真正的透明背景 PNG（帶 alpha 通道）。不要白底、不要灰白棋盤格、不要地面陰影、不要格線或邊框，
四隻之間用留白分開，代號字母放在每隻的正下方。
```

## 第 1 步：角色設定稿

把 `{選定的風格}` 換成第 0 步挑中的那一段描述（例如「B. 精緻平塗貼圖風：乾淨俐落的輪廓線，賽璐璐兩階陰影」），並附上第 0 步的圖：

```
請以附圖中 {代號} 的畫風，為這隻 Q 版水豚畫正式的角色設定稿。

角色：圓滾滾的 Q 版水豚，暖棕色短毛，小圓耳朵，豆豆眼，一臉悠哉，頭上頂著一顆小橘子。2～3 頭身。
畫風：{選定的風格}

內容：同一隻角色的正面、3/4 側面、正側面（面向右）三個角度，並排站在同一條水平線上，大小一致。

品質要求：商業產品等級，細節乾淨、比例精準、光源統一從左上方來；縮小到 128 像素仍要認得出來。
背景：真正的透明背景 PNG（帶 alpha 通道）。不要白底、不要灰白棋盤格、不要地面陰影。
角色外圍不要光暈、外發光、邊緣補光。
不要文字、不要邊框、不要其他物件。
```

## 第 2 步：動作圖（一張圖 4 個姿勢）

ChatGPT 出圖次數有限，所以**一張圖畫 4 個姿勢，排成 2×2**（風格探索那張已經驗證過：4 隻一起出、透明背景照樣成功）。
程式這邊用 `Youban.exe --slice` 自動找出每一隻、裁好、依「左上 → 右上 → 左下 → 右下」命名，不用手動切：

```
Youban.exe --slice <多格圖.png> capybara walk_01 walk_02 walk_03 walk_04
```

開新對話、附上 `art/<桌寵>/reference.png`，「共用規範」**只貼一次**，之後每次貼一組。
四格裡有一隻歪掉：跟 ChatGPT 說「只重畫第 X 格」，不用整張重來。

### 共用規範

```
附圖是我的桌面寵物角色設定稿。接下來我每次請你畫一組動作，一張圖裡畫 4 個姿勢（排成 2×2），整個對話都照這些規則：

- 四格都是附圖這隻角色：比例、配色、毛色、頭上的小橘子、輪廓線粗細、畫風、光源方向完全一樣
- 四格裡角色的大小一致、腳底（或貼地的身體）在各自格子裡的同一個高度
- 格與格之間留大片空白分開（至少半個角色寬），不要畫格線、邊框、編號、文字
- 排列順序：左上 → 右上 → 左下 → 右下
- 真正的透明背景 PNG（帶 alpha 通道），不要白底、不要灰白棋盤格、不要地面陰影
- 角色外圍不要光暈、外發光
- 品質：商業產品等級，細節乾淨
```

### 六組（照平常最常看到的排優先）

| 組 | 四格（左上 → 右上 → 左下 → 右下） | 切圖名稱 |
|---|---|---|
| 1 走路 | 四格都是正側面、面向右、慢悠悠地走：① 右前腳與左後腳往前踏 ② 四腳靠攏、身體在最高點 ③ 左前腳與右後腳往前踏 ④ 四腳靠攏、身體在最高點（腳的前後與 ② 相反） | `walk_01` `walk_02` `walk_03` `walk_04` |
| 2 睡覺＋提醒 | ① 趴著睡，四腳收在身體下、眼睛閉著 ② 同一個睡姿、吸氣身體微微鼓起 ③ 正面站立、前腳舉起金色小鈴鐺搖動、表情認真 ④ 同 ③、鈴鐺擺到另一邊、嘴巴張開像在喊 | `sleep_01` `sleep_02` `notify_01` `notify_02` |
| 3 拎起來＋掉落 | ① 被人從背上拎起來懸空、四腳自然下垂、一臉無所謂 ② 同樣懸空、四腳在空中划動、有點困惑 ③ 從空中往下掉、四腳張開、小橘子微微飄起、驚訝 ④ 剛落地、身體壓扁一點、四腳彎曲緩衝 | `drag_01` `drag_02` `fall_01` `land_01` |
| 4 心情 | ① 正面、前腳舉起、眼睛笑成彎月、臉頰泛紅 ② 正面、開心地跳起離地、小橘子跟著彈起 ③ 像人一樣坐著、屁股著地、前腳放肚子上 ④ 跟設定稿正面完全相同的站姿、只有眼睛閉起來 | `happy_01` `happy_02` `sit_01` `blink_01` |

| 6 爬牆＋說話 | ① 側面身體直立、四腳抓著右邊的牆往上爬（牆不用畫）、面向右 ② 同 ①、換另一組腳往上 ③ 正面站立、一隻前腳比向旁邊像在解說、嘴巴閉著 ④ 同 ③、嘴巴張開在說話 | `climb_01` `climb_02` `talk_01` `talk_02` |

貼法：共用規範之後，每次貼「第 N 組：」加上那一列的四格描述。

**想要更順的動作**：先出好關鍵姿勢，再用這段補中間（一樣可以一次要 4 張過渡）：

```
附圖是同一隻角色同一個動作的第 {N} 張與第 {N+1} 張。請畫出這兩張正中間的過渡姿勢，
其他條件（角色、大小、位置、透明背景）完全照共用規範。
```

## 常見問題

- **背景變成灰白棋盤格** → 回它：「這是畫出來的棋盤格，不是透明。請輸出真正帶 alpha 通道的透明背景 PNG」。還是不行就停，傳給我改做法
- **角色長得跟設定稿不一樣** → 重新附上設定稿，加一句「臉型、毛色、小橘子的位置和附圖一模一樣」
- **同一組動作大小不一** → 匯入工具會統一大小，但差太多會被擋下來；單獨重出那張
