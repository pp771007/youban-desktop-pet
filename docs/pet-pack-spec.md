# 桌寵包規範（spec 1）

每隻桌寵是一個「桌寵包」資料夾。照這份規範做，放進 `pets/` 就能在執行中切換使用。

**原則：規範只訂「下限」，不訂上限。** 每個狀態要幾張、多大張、每張停多久，都由桌寵包自己決定；
圖越精緻、張數越多，動畫就越順。引擎補的動態效果（呼吸、彈跳…）只是**沒有足夠張數時的墊底**，可以逐狀態關掉。

## 1. 狀態表

**只有 `idle` 一張是必要的** —— 一張站姿圖就是一隻能用的桌寵，其他動作之後慢慢補。
缺圖的狀態一律用替代規則頂上，最後都會落到 `idle` 那張圖＋引擎動態效果。補上圖之後引擎自動改用真的圖。

| 狀態 id | 必要 | 最少張數 | 循環 | 缺少時 | 引擎墊底效果（預設開） | 預設身高比例 |
|---|---|---|---|---|---|---|
| `idle` 站著 | ✅ | 1 | 是 | — | 呼吸縮放 | 1.00 |
| `walk` 走路 | | 1 | 是 | `idle` | 一跳一跳＋左右搖擺 | 1.00 |
| `drag` 被拎起來 | | 1 | 是 | `idle` | 跟著滑鼠像鐘擺晃 | 1.05 |
| `fall` 掉落中 | | 1 | 是 | `idle` | 往下拉長 | 1.00 |
| `sleep` 睡覺 | | 1 | 是 | `idle` | 慢呼吸＋飄 Zzz | 0.55 |
| `notify` 提醒你 | | 1 | 是 | `idle` | 輕微跳動 | 1.00 |
| `blink` 眨眼 | | 1 | 否 | 不眨眼 | — | 1.00 |
| `happy` 開心（被點） | | 1 | 是 | `idle` | 跳一下 | 1.05 |
| `sit` 坐下 | | 1 | 是 | `idle` | 呼吸縮放 | 0.80 |
| `land` 落地 | | 1 | 否 | `fall` | 壓扁再回彈 | 0.85 |
| `yawn` 打哈欠（要睡了） | | 1 | 否 | 直接 `sleep` | — | 1.00 |
| `wake` 伸懶腰（醒來） | | 1 | 否 | 直接 `idle` | — | 1.10 |
| `talk` 說話 | | 1 | 是 | `notify` | — | 1.00 |
| `hop` 原地小跳 | | 1 | 否 | `idle` | 跳一下、起落壓扁 | 1.00 |
| `look` 左右張望 | | 1 | 否 | `idle` | 轉頭看另一邊再轉回來 | 1.00 |
| `doze` 打瞌睡 | | 1 | 是 | `idle` | 頭往前點兩下 | 0.95 |
| `climb` 爬螢幕邊 | | 1 | 是 | `walk` → `idle`，並轉 90 度、腳貼著牆走上去 | 一步一步離牆一點點 | 1.00 |

`climb` 的圖：身體直立、側面貼在牆上往上爬，**面向右**（牆在右邊）；爬左牆時引擎左右翻轉。

表情特效（愛心、汗滴、驚嘆號、落地灰塵、音符、問號）由引擎用向量畫，每一隻桌寵都有，不用出圖。

- 往左走：沒提供 `walk_left` 時，引擎把 `walk` 左右翻轉。角色有不對稱的細節（例如單邊的配件）就另外提供 `walk_left`。
- 身高比例：以 `idle` 為 1.00，匯入工具把每個狀態縮放到這個比例（AI 每張畫的大小都不同，不能照原圖）。
  不對就改 `pet.json` 的 `heightRatio`。

### 1.1 變化款（同一狀態多種演法）

同一個狀態可以有多個變化款，引擎依權重隨機挑，避免一直重複同一套動作。
例：`idle` 底下有「一般站著」「東張西望」「抓抓頭」三款。

### 1.2 自訂狀態

規範之外的狀態（例如之後的「吃東西」「打字」）直接用新 id 加進 `pet.json`；
引擎認不得的狀態不會報錯，等哪個功能模組用到時才播。新功能要用新動作，不必改規範版本。

## 2. 原始圖（交給匯入工具的）

### 2.1 接受兩種格式

| 格式 | 檔名 | 適合 |
|---|---|---|
| 一張一幀 | `<狀態>[-<變化款>]_<序號>.png`，例：`walk_01.png`、`idle-look_03.png` | ChatGPT 逐張出圖 |
| 整張精靈圖（sprite sheet） | `<狀態>[-<變化款>].sheet.png`，在 `import.json` 寫幾欄幾列 | Aseprite 等專業工具匯出 |

另附 `reference.png`（角色設定稿）。

### 2.2 圖的規定

| 項目 | 規定 | 為什麼 |
|---|---|---|
| 背景 | **真正的透明 PNG（帶 alpha 通道）** | 邊緣的半透明羽化能完整保留，不會有去背的混色、切爛 |
| 尺寸 | 不限，建議 1024 以上；同一個狀態的每張要一樣大 | 同一狀態尺寸不同，匯入工具會拒收並列出哪幾張 |
| 構圖 | 全身入鏡、不碰邊；同一狀態的每一張，角色在畫面中的位置與大小保持一致 | 動畫才不會抖 |
| 方向 | 側面類一律**面向右** | 往左由引擎翻轉 |
| 不要有 | 地面陰影、文字、Zzz、對話框、邊框、背景物件 | 引擎會畫；畫在圖裡會重複 |

> 若驗證發現 ChatGPT 給不出真正的透明背景，退回方案（純色背景＋去背）另行處理，規範的其他部分不變。

## 3. 匯入工具 `petpack import`

1. **驗透明**：沒有 alpha 通道、或背景是「畫出來的棋盤格」→ 拒收，指出是哪一張
2. **驗一致**：同一狀態的尺寸不同、角色位置跳太多 → 列出來給你看
3. **清掉幾乎看不見的殘影**：AI 圖常在角色外圍留一大片透明度只有 1～3% 的霧，肉眼看不到，
   但會讓裁切外框變大、滑鼠點擊範圍變成一整塊方形。低於門檻的歸零；接近不透明（≥ 248）的補成完全不透明
4. 裁到角色外框，依身高比例縮放，**保留原本的半透明邊緣**
5. **對齊錨點**：角色最低點的水平中心放到固定位置，換狀態不會跳位
6. 輸出標準桌寵包，並產生總覽圖＋每個狀態的預覽動畫 —— **你看過沒問題才裝進 `pets/`**

## 4. 桌寵包格式

最小的桌寵包：

```
pets/<id>/
  frames/idle_01.png        # 任何大小的透明 PNG，引擎載入時自己裁邊、對齊腳底
```

完整的桌寵包：

```
pets/<id>/
  pet.json                  # 選用；沒有就全部用預設值，名字用資料夾名
  thumb.png                 # 選用；沒有就用 idle 第一張縮小
  frames/<state>[-<variant>]_<nn>.png
```

引擎載入時對每張圖做第 3 節的 3～5 步（清殘影、裁邊、對齊錨點），所以 ChatGPT 出的原圖直接放進 `frames/` 就能用；
匯入工具是給「一次匯入一大批、想先看總覽與預覽動畫」時用的，不是必經之路。

- 每格大小由 `cell` 宣告（預設 512，可以更大）。格子是正方形，角色最低點的水平中心固定在 `anchor`。
- 引擎依目前的顯示大小與螢幕縮放比例，從原圖高品質縮小 —— 所以原圖越大，高解析度螢幕上越細緻。

```json
{
  "spec": 1,
  "id": "capybara",
  "name": "水豚",
  "author": "",
  "accent": "#C8925A",
  "cell": 512,
  "anchor": [256, 496],
  "states": {
    "idle": {
      "variants": [
        { "id": "default", "weight": 6, "frames": 2, "fps": 2 },
        { "id": "look",    "weight": 1, "frames": 12, "durations": [200, 80, 80, 80, 600, 80, 80, 80, 600, 80, 80, 200], "procedural": false }
      ]
    },
    "walk":   { "frames": 8, "fps": 12, "speed": 40, "procedural": false },
    "drag":   { "frames": 2, "fps": 4, "heightRatio": 1.05 },
    "fall":   { "frames": 1 },
    "sleep":  { "frames": 2, "fps": 1, "heightRatio": 0.55 },
    "notify": { "frames": 4, "fps": 6 }
  }
}
```

| 欄位 | 意思 |
|---|---|
| `spec` | 規範版本。日後改版，舊版的包由引擎自動轉換照樣能用 |
| `accent` | 這隻的強調色，對話泡泡與頭上的框的重點色會換成它（見 `design-system.md`） |
| `frames` + `fps` | 張數與每秒幾張（等速） |
| `durations` | 每一張各停幾毫秒（不等速，做「停頓」「預備動作」用）；有它就不看 `fps` |
| `variants` | 變化款與權重 |
| `procedural` | `false` = 關掉這個狀態的引擎墊底效果（圖已經夠順時關掉，免得疊兩層） |
| `speed` | 走路速度（像素／秒，以中尺寸計）。要配合腳步張數調，腳才不會在地上滑 |
| `heightRatio` | 覆寫預設身高比例 |
| `loop` | 覆寫預設的循環與否 |

沒列出來的選用狀態 = 沒有，照第 1 節的替代規則。

## 5. 執行時的記憶體

張數不設上限，記憶體靠「載入策略」管，不靠限制美術：

- **只解碼成目前顯示尺寸**。原圖 1024 也好 2048 也好，記憶體裡只放顯示大小（中尺寸 128px、150% 縮放時約 192px，一張約 144KB）。
- **常用狀態常駐、少用的用到才載**：`idle`、`walk`、`drag`、`fall` 常駐；其他第一次播時才解碼，
  總量超過預算（預設 32MB）就丟掉最久沒播的。
- 切換清單只讀 `pet.json` 與 `thumb.png`，不載入任何幀。
- 換桌寵時舊的那包整個丟掉。
